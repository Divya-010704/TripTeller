 🌍 Trip Teller – Smart Travel Experience Sharing

📌 Description
Trip Teller is a smart and interactive web application that helps users plan trips and share travel experiences in one platform. It combines personalized trip planning with a social community where users can post, like, and comment on travel experiences.

---

🎯 Objective
- To provide personalized trip planning based on budget, duration, and mood  
- To create a platform for sharing travel experiences  
- To build a community-driven travel system  

---

## 🚀 Key Features

🧭 Trip Planning Module
- Manual trip planning  
- Mood-based trip planning (Adventure, Relaxation, Culture, Family)  
- Budget-based suggestions  
- Day-wise itinerary generation  

🌐 Experience Sharing Module
- User registration & login  
- Create profile  
- Upload photos & videos  
- Share travel experiences  
- Like and comment on posts  

👥 Social Features
- Follow/unfollow users  
- View profiles  
- Community interaction  

🛠️ Technologies Used
- Frontend: React.js  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- Media Storage: Cloudinary  
- Languages: HTML, CSS, JavaScript  

🏗️ Architecture
The system follows a client-server architecture:
- Frontend handles UI and user interaction  
- Backend manages API and logic  
- MongoDB stores user and trip data  
- Cloudinary stores images and videos  

 ⚙️ 1. How to Run the Project

 1. Clone Repository
   
### 2. Backend Setup

### 3. Frontend Setup
